## 3. What I changed and why

- Separated functions: Website opening, music, news, time, and date each have their own functions. This makes debugging easier.
- Removed the duplicate API request: The news function makes only one request.
- Kept your music library: It still uses `musicLibrary.music[song]` through the same dictionary.
- Improved error handling: Handles empty headlines, network errors, speech recognition failures, and unknown songs.
- Improved microphone handling: Calibrates once and reuses the microphone instead of repeatedly opening it.
- Added a shutdown command: You can exit without manually interrupting the terminal.

### One limitation to understand

This is a command-based voice assistant, not a continuously intelligent AI assistant. It recognizes predefined commands using Google's speech recognition service. It won't automatically understand arbitrary instructions or hold a conversation like ChatGPT.

My recommendation: Get this version running reliably first. Then add one feature at a time—volume control, system app launching, weather, reminders, and eventually an LLM for natural-language commands. That approach will teach you more than adding ten features at once and debugging them together.
